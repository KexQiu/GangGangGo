# 移动端同步

`SyncCoordinator` 是唯一自动同步入口。它在启动、登录变化、本地记录变化和回到前台时收集原因，750ms 防抖，并保证同一时间只有一轮任务运行；运行期间的新变化合并为一次尾随同步。

完整记录、共享快照、兼容的 90 天报告、Push 注册和 Watch 状态互不依赖时并行执行。任一云端失败不得回滚本地 mutation。服务端查询通过 TanStack Query key 去重，会话切换时清空缓存。

完整记录使用 SQLite outbox 和服务端单调游标：本地事实与 outbox 在同一事务提交，服务端按 mutation ID 幂等接收，同一实体以最后被服务端接受的变更为准。所有登录用户都执行完整同步；Pro 只控制 90 天日历和高级趋势的查看能力。

本地数据按 profile 隔离。首次登录会接管当前未归属记录，之后切换账号使用各自 profile；退出登录后切回新的未归属 profile。健康事实与每日汇总保留 90 天，自定义小信号常用项持续保留。
