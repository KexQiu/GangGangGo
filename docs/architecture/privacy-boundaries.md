# 隐私与数据边界

更新日期：2026-09-28

本地 SQLite 保存训练记录、小账本状态、具体蹲会儿时长、排便细节、自定义小信号和每日汇总。登录后，这些个人完整记录以普通结构化字段同步到账号云端，不做应用层端到端加密；API 必须通过会话按 `user_id` 隔离。

## 保留策略

- 个人健康事实、同步变更和每日汇总：90 天。云端按记录日期和记录时区判断过期，由独立定时任务清理；本机在启动时清理当前资料中超过 90 天的健康记录、汇总及过期待上传记录，不承诺永久本地保留。
- 增长事件：按服务端 `received_at` 保留 90 天。
- 自定义小信号常用项：仍在使用时不随健康事实窗口过期。
- 认证会话到期后、过期邀请、临时好友事件和旧每日计数：由独立定时清理任务删除。已撤销会话的 refresh 摘要保留至到期，仅用于原会话 family 的离线退出补偿。

清理只由 `retentionService` 和运维任务触发，不在用户上传增长事件的请求链路内顺带执行。

## 好友共享

好友读取直接基于云端每日汇总与按好友授权设置。默认不共享；训练、小账本和蹲会儿分别支持 none/summary/detailed 投影。服务端在响应层裁剪未授权字段，contracts 使用 strict Zod schema 拒绝额外字段。

- 训练低敏：当天是否达标；完整：另含完成组数、完成次数和总时长。
- 小账本低敏：当天记录项数、连续记满四项的天数；完整：另含饮水、膳食纤维、活动和排便习惯等级。
- 蹲会儿低敏：当天是否有记录；完整：另含记录次数、总时长、中位数、最长时长、达到 10 分钟次数、感受/形状/颜色分类次数、需留意次数及自定义小信号原文与各自出现次数。需留意计数包含便血、不适、颜色需留意或有小信号的记录。

权限在每位好友上独立保存，历史范围为今天、7 天或 30 天。撤销后服务端停止提供该类健康数据，无法收回对方已看过或自行保存的内容。调整好友共享不影响个人云端同步。

“我的”与邀请加入页在发起登录前共用 `LoginSyncSheet`，说明匿名资料归属、同步字段、历史与保留期；取消不会发起登录或合并资料。`dataDisclosure.ts` 通过契约字段映射约束用户可见说明，后续新增字段必须补充描述。真实 Apple 登录仍由 R01 单独跟进。

## 账号导出与删除

`GET /me/export` 导出资料、同步健康数据、每日汇总、好友关系与事件、增长事件、订阅和审计关联数据。导出不包含 access/refresh token、refresh token 摘要、Push token 原文或 Apple 身份凭据。

`DELETE /me` 永久删除云端账号。外键级联删除同步数据、会话、好友关系、Push token 和订阅主体；服务显式删除原本会通过 `SET NULL` 匿名保留的增长、审计与订阅事件关联数据。删除后移动端清理登录会话并切回本地匿名 profile；本机 SQLite 健康记录不会被云端接口自动删除。

正式发布前仍需把上述规则同步到用户可见隐私政策，并明确审计事件的最终法定保留期限与备份擦除流程。

## 设备与日志

iOS 在 SQLite 初始化后通过 `apps/mobile/modules/storage-protection` 设置文件保护，并对数据库目录、主文件、WAL 和 SHM 标记 iCloud 备份排除。

日志不得包含 token、健康详情、完整 Watch payload 或账号导出正文。API 只记录请求元数据、状态、耗时和已脱敏错误。
