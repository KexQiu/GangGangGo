# 隐私与数据边界

本地 SQLite 保存训练记录、小账本状态、具体蹲会儿时长、排便细节、自定义小信号和每日汇总。登录用户的这些个人完整记录会以普通结构化字段同步到账号云端，不做应用层端到端加密；API 必须通过登录会话按 `user_id` 隔离访问。

个人健康事实、变更日志和每日汇总只保留 90 天，过期数据由移动端启动清理和服务端每日清理任务共同删除。仍在使用的自定义小信号常用项不随 90 天窗口过期。

完整记录同步与社交共享是两条数据通道。小队共享快照仍只允许日期、训练是否达标、小账本完成度、是否记录过蹲会儿和连续天数；个人高级报告兼容接口额外允许“是否长会”这一日级布尔值，但不进入小队共享。contracts 使用 strict Zod schema 拒绝额外字段。日志不得包含 token、健康详情或完整 Watch payload。

iOS 在 SQLite 初始化后通过 `apps/mobile/modules/storage-protection` 设置 `completeUntilFirstUserAuthentication` 文件保护，并对数据库目录、主文件、WAL 和 SHM 标记 iCloud 备份排除。
