# R14/R15/R19/R20 提醒、训练计时与可读性

日期：2026-09-29；基于 `f7a5786`。本批处理审查清单最后四项代码问题；设备验收和发布准备仍独立跟踪。

## R14/R15：每日重复提醒与勿扰边界

- 久坐提醒改为系统 `DAILY` 触发器，按每天本地时间重复，不再只生成今天、明天的一次性通知。最短 45 分钟间隔最多 15 个久坐时段，加上最多 3 个训练时段，总量不随天数增长。
- 久坐活动时间固定为 `[09:00, 21:00)`。扣除勿扰后，每个可提醒窗口从起点经过一个完整间隔再开始提醒；窗口与勿扰均采用 `[开始, 结束)`，最终候选再次检查勿扰。全天被覆盖时不会安排通知。
- 例如间隔 60 分钟、勿扰 `[12:00, 14:00)`：提醒在 10:00、11:00、15:00…20:00；12:00 不再误发。14:00 已不属于勿扰，但本策略在恢复活动一小时后才提醒。
- 启动、回前台、前台日期/时区变化以及上一提醒时间经过后校准。界面使用通知库返回的下次触发时间显示“下次预计”，而不是从设置推导已安排成功。
- 设置持久化、权限检查和排程串行执行；设置保存失败保留原设置，快速开关不会被迟到旧任务覆盖。排程失败清理部分计划，隐藏旧成功状态并提供重试。
- 只清理训练/久坐提醒，不删除排便阶段通知。系统每日重复与本机无需每天打开的策略已接入；实际送达仍受系统权限、专注模式和省电策略影响，页面已说明。

## R19：前台训练、后台暂停与恢复

- 产品规则：锁屏、来电进入 inactive、切后台或离开训练页均暂停，返回后手动继续。不会把无人跟随动作的后台时间累计成已完成训练。
- 使用单调时钟 `performance.now()` 的时间差计算前台进度，回调只刷新展示和保存进度；卡顿后会校准，暂停保留不足一秒的时长，训练时长不超过对应预设。
- 每秒及暂停/结束时保存本地进度，按 profile 隔离。重启恢复已保存的 ID、模式、开始时间和进度，并保持暂停，不补算进程关闭时段。异常退出可能丢失上次成功保存后尚未观察到的前台时间。
- 保存进度失败会暂停并显示错误；账号切换后原训练不能写入新账号。退出旧页面保留原 profile 的暂停快照。
- 结束时固定记录 ID 与结束时间；重启重试仍使用相同记录。训练仓储在事务内拒绝同 ID 不同内容/不同归属，完全相同的已保存记录不会重复写入统计和 outbox。
- 本地训练进度不上传云端。进入训练时若存在未完成进度，会优先恢复原模式；用户可继续、结束保存或主动放弃。

## R20：文字、按钮和图表

- 新增 `primaryForeground`：浅色主按钮使用加深绿色配白字，深色主按钮使用亮绿色配深色字；聊天的主色气泡同样沿用该前景色。
- 提高弱文本与信息、警告、错误文字的对比度。禁用按钮使用明确的背景/文字颜色和禁用语义，不再降低整个控件透明度；选中项补充无障碍状态。
- 主要按钮普通/按下状态的文字对比度，浅色分别约 5.15:1 / 7.01:1，深色约 9.60:1 / 7.11:1。自动化覆盖正文、弱文本、禁用、选中、警告和错误文字的实际 token 组合，最低 4.5:1。
- 移动端原有 9–11 单位信息字号提升到至少 12。按钮支持换行及纵向留白，图表摘要不再固定高度或截成单行。
- SVG 轴字号按实际容器宽度校准；大字体或窄屏使用图表下方的原生可缩放刻度/日期说明，避免把多组大字挤进坐标轴。选中日期和值继续使用原生文字与可访问的前后日操作。
