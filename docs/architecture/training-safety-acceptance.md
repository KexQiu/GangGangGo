# 菊花抬训练修复验收

日期：2026-09-29。范围：手机、Watch、SQLite/Postgres、同步、好友展示与设置。此文记录工程实现和验收边界，不作为临床审核结论。

## 实现清单

| 批次 | 改动 | 核心验收口径 |
| --- | --- | --- |
| 节奏与停止 | 显式阶段；3 秒准备；迟到超过 250 ms 暂停；完整放松后计次 | 不从累计时长补算次数；暂停后不保留收缩指令 |
| 生命周期 | 后台/离页/确认框暂停；冷启动暂停；跨日旧进度不续练 | 用户主动继续且先完整放松；连续前台跨午夜可完成 |
| Watch | 单调时间；权限失效暂停；原 owner 草稿；异步可靠入队 | 权限恢复前不跨账号保存；终点不显示“放松 0”或因点击暂停而完成 |
| 记录 | 冻结草稿后询问三态反馈；不适立即停止；稳定 ID/结束时间 | 保存失败、重启、重复 ACK 不重复记录或改变已提交内容 |
| 契约与迁移 | plan/endReason/feedback；v6 状态/v4 事件；SQLite v5/Postgres 0002 | 保留数据；仅修正可确定的旧 Watch 次数；待上传数据一并转换 |
| 设置与共享 | 各预设参数；默认无目标；资料隔离；长期配置同步 | 活动快照不变；部分记录在好友页为已记录，反馈/目标/参数不共享 |
| 引导与提醒 | 首次动作说明、重复查看、暂停训练提醒 | 阅读不是筛查；提醒独立于目标，保留时间且不自动重开 |
