# 肛肛好整体风格设计指南

版本：v0.2  
日期：2026-05-18  
阶段：当前视觉与文案规范  
关联文档：[产品定位文档](./product-positioning.md)、[PRD](./prd-v0.1.md)

## 1. 设计定位

肛肛好的整体风格是：

**轻松克制、隐私友好、可信赖的私密健康习惯工具。**

它不是医院 App，也不是恶搞 App。界面要让用户敢打开、愿意每天点一下，并且在风险场景中知道应该认真处理。

## 2. 当前体验原则

### 2.1 单首页优先

当前 App 不使用底部 Tab。首页就是今日行动中心，用户打开后应能完成大部分高频动作：

- 看今日状态。
- 看今日正反馈。
- 看最近趋势入口。
- 开始菊花抬。
- 开始马桶计时。
- 快速小账本打卡。
- 查看小暗号和安全说明。

### 2.2 轻松但不低俗

可以使用“小花、开张、下班、收工、小暗号、小账本”等轻松表达，但不能出现低俗段子、身体羞辱或夸张恶搞。

### 2.3 正反馈但不强游戏化

正反馈要让用户感到“做了一点也有价值”，但不使用积分、等级、排行榜、金币、烟花或强刺激动效。

### 2.4 风险场景严肃

明显便血、明显不适、剧烈疼痛、症状加重等场景必须清晰表达，并建议咨询医生。此类场景不使用庆祝文案。

## 3. 视觉关键词

- 温和
- 私密
- 轻松
- 工具感
- 低负担
- 有完成感
- 不制造焦虑

## 4. 不采用的风格

### 不做医疗恐惧风

避免病理图片、医生插画、大面积红色、医院病历感。

### 不做低俗搞笑风

避免夸张身体部位、黄色段子、恶搞表情、过度拟人化器官。

### 不做健身热血风

避免挑战极限、排行榜、连续打卡压迫、燃烧卡路里式成就。

### 不做复杂数据风

趋势页只展示轻量趋势，不做医疗分析、健康评分或复杂报告。

- 危险色仅用于明显便血、明显不适、就医提示等风险。

## 6. 组件规范

### Screen

- 页面背景使用 `colors.background`。
- 默认只包含顶部安全区。
- 无底部导航时，训练中和计时中页面可显式保留底部 safe area。

### AppTopBar

- 二级页统一使用。
- 返回按钮触控区域 44x44。
- 训练中、计时中使用关闭图标，并在中途退出时弹确认。

### AppCard

- 用于独立功能块。
- 不在卡片里嵌套卡片。
- 默认圆角 24，边框使用 `colors.border`。

### AppButton

- 主按钮表达明确动作，如“开始菊花抬”“开始营业”“记好了”。
- 次按钮用于设置、查看说明、精细记录。
- 风险动作不使用大红实心按钮。

### 状态标签

用于首页状态块：

- 菊花抬：待营业、已开张、已下班。
- 小账本：待开张、已记录、满格。
- 马桶计时：未记录、已入账。

标签必须短，不塞完整句子。

## 7. 核心页面规范

### 7.1 首页

首页目标：用户 3 秒内知道今天做了什么、下一步做什么。

顺序：

1. 标题和右上角设置。
2. 三个状态块。
3. 今日反馈卡。
4. 最近趋势入口。
5. 菊花抬主行动卡。
6. 马桶计时、小账本快捷行动。
7. 快速小账本打卡。
8. 小暗号提醒状态。
9. 安全说明入口。

视觉重点：

- 菊花抬是最大主行动。
- 今日反馈卡给轻量鼓励。
- 趋势入口明显但不抢主行动。
- 安全入口可见但不制造焦虑。

### 7.2 菊花抬

页面目标：让用户跟着节奏完成训练。

视觉规则：

- 训练中页面使用大倒计时。
- 收紧和放松阶段有不同提示。
- 完成页使用对勾和轻量 success haptic。
- 不使用烟花、金币或夸张动效。

文案示例：

- 轻轻抬一下。
- 好，放松。
- 呼吸在线，轻提，不用猛。
- 小花可以下班一会儿。

### 7.3 马桶计时

页面目标：极简、防刷手机、及时收工。

状态文案：

- 正常营业。
- 5 分钟敲门。
- 10 分钟提醒。
- 马桶不是第二工位。

视觉规则：

- 普通阶段不用红色。
- 10 分钟后使用 warning。
- 便血、不适等红灯信号才使用 danger。
- 不鼓励用户增加马桶计时次数。

### 7.4 小账本

页面目标：快速记录，不像填问卷。

规则：

- 首页快速打卡一点即记为达标。
- 详情页三档可调整。
- 满格时突出“小账本满格”。
- 连续完整打卡可展示天数，但不做排行榜。

### 7.5 最近趋势

页面目标：让用户看到“最近确实有坚持”。

结构：

- 顶部趋势反馈卡。
- 最近 7 天三张趋势卡。
- 最近 30 天摘要。
- 风险提示卡。

趋势卡规则：

- 菊花抬：柱子代表每日完整完成组数。
- 小账本：柱子代表每日完成项数，满格日用主色。
- 马桶计时：只展示是否入账；长会用 warning，红灯用 danger。
- 无记录时显示空状态，不显示空图表。

### 7.6 小暗号设置

页面目标：让用户相信提醒不会尴尬。

文案方向：

- 小暗号。
- 小花营业。
- 换个姿势。
- 闭麦时间。

隐私模式下避免出现“提肛”“肛门”等敏感词。

### 7.7 安全说明

页面目标：轻松说明，但红灯信号明确。

模块：

- 怎么抬比较稳。
- 这些情况先别抬。
- 这些信号别拖。
- 常见翻车姿势。

风险文案必须清楚：

- 明显便血。
- 剧烈疼痛。
- 不适加重。
- 建议咨询医生。

## 8. 文案语气

### 总体语气

短、轻、清楚、有边界。

### 当前术语

| 术语 | 含义 |
| --- | --- |
| 菊花抬 | 提肛训练 |
| 小花 | 对训练部位的轻松隐喻 |
| 小暗号 | 隐私提醒 |
| 马桶计时 | 如厕时间计时 |
| 收工 | 结束马桶计时 |
| 小账本 | 健康习惯打卡 |
| 开张 | 今天已经开始记录或训练 |
| 下班 | 今日建议量已完成 |
| 长会 | 马桶计时超过 15 分钟 |
| 红灯信号 | 便血或明显不适 |

### 可以使用

- 今天不是空白页。
- 小花已开张。
- 小账本满格。
- 收工已入账。
- 今天不用卷了。
- 能少开长会就少开。
- 先别硬扛，建议咨询医生。

### 避免使用

- 挑战极限。
- 冲榜。
- 打败多少人。
- 治好痔疮。
- 根治便秘。
- 你可能得了某某病。
- 不练就会出问题。

## 9. 动效和反馈

### 原则

- 轻、短、稳定。
- 不制造兴奋或压力。
- 正反馈是确认感，不是游戏奖励。

### 当前反馈

- 按钮按下轻微透明和缩放。
- 训练阶段切换使用轻震。
- 菊花抬完整完成使用 success haptic。
- 马桶记录无风险保存时使用 success haptic。
- 风险场景不使用庆祝反馈。

## 10. 可访问性

- 点击区域不小于 44。
- 状态不能只靠颜色表达，必须有文字。
- 深色模式下 warning 和 danger 要保持可读。
- 大倒计时要稳定，不因数字变化导致布局跳动。
- 小柱状图必须有数字和日期标签辅助理解。
- 风险提示不能只用红色表达。

## 11. 设计资产说明

`docs/previews/` 中的早期预览图仅作为历史参考，不是当前 UI 的实现标准。

当前 UI 的真实标准以以下内容为准：

- 当前 App 页面实现。

后续如需生成视觉预览，应优先使用位图预览，不以 SVG 作为最终视觉交付。

## 12. 当前设计结论

肛肛好当前设计方向是：

**单首页承载高频动作，用轻松文案降低尴尬，用今日反馈和趋势页提升坚持感，用安全说明守住健康边界。**

后续设计新增功能时，应优先检查：

1. 是否让首页更复杂。
2. 是否让用户更尴尬。
3. 是否暗示治疗效果。
4. 是否鼓励过度训练或过度记录。
